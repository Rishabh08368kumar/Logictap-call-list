# Logictap call list (Part 3)

A call list page for a clinic owner. Plain HTML, CSS and JavaScript. No build step, no server.

- `index.html` is the final page
- Data is inside `index.html` (exactly as the server sends it)
- `v1.html` is the first code the AI gave, untouched
- `screenshots/` has the screenshots used in the PDF

Open `index.html` in a browser. To host it, turn on GitHub Pages (Settings > Pages > main branch, root).
